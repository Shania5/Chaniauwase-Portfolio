01 / Automation & PLC programming

Pick-and-place sequence control.

Siemens TIA Portal · Ladder logic · Submitted lab implementation · 2023

I organised the application into equipment-status, automatic-sequence, and output-control function blocks. The sequence moves a workpiece to the conveyor middle, picks up an insert, raises and transfers it, releases it onto the workpiece, and moves the workpiece onward.

  • A 300 ms on-delay timer participates in the transition from conveyor movement to pickup.
  • Vacuum and suction-cup conditions determine when pickup and raising states advance.
  • Manual slide commands require jog enable and the suction-cup-up input.

The exports demonstrate program structure and operational permissives. They do not establish comprehensive fault recovery or validated safety functions. Some equipment-status tags represent commanded output states, rather than independently measured positions.

02 / HMI & SCADA integration

Connecting operator commands to PLC logic.

Ignition · Siemens PLC · KEPServerEX · OPC UA · Academic final project, 2023

I developed an Ignition interface for extension and retraction commands, connected it to PLC tags through Kepware, and documented the ladder logic and pneumatic connections.

Integration troubleshooting

My report records missing channel data and bad tag quality during configuration. Reconnecting the Kepware runtime and rebuilding the tag configuration restored the reported data exchange. Those are documented recovery steps; the report does not isolate a single root cause.

The demonstration video includes online ladder states and HMI state changes. The submitted interface indicates commands; separate cylinder-position feedback is not established by these files.

Additional operator-interface example +

My high-performance HMI exercise also explored analog indicators, radar charts, and sparklines. Its report notes a tag-history problem, so I do not present the trend display as fully verified.

03 / Industrial controller integration

Storage-station communication sequencing.

Siemens PLC · Function blocks · Digital I/O handshake · Submitted implementation, 2024

The PLC commands a separate station motor controller through digital I/O. I separated colour detection, storage sequencing, communication sequencing, and output control into function blocks.

The communication sequence handles station referencing, automatic-mode enable, colour-code selection, a strobe command, and waiting for controller responses. This is digital I/O handshaking, rather than direct PLC control of every gantry movement.

This selection documents the storage-sequence iteration. Retrieval interfaces, complete fault handling, and alarm acknowledgement were later assignment requirements; they are not claimed as completed from this report.

Related sensing exercise: colour detection +

A separate exercise used metallic and not-black sensor inputs, plus a CTU counter with preset 2 to identify two detection pulses associated with transparent workpieces. The submitted version needs its between-workpiece reset and colour-code mapping reconciled before repeatable four-colour classification can be claimed.

05 / Industrial network documentation

Addressing across two production lines.

Microsoft Visio · Ethernet subnet planning · PROFIBUS addressing · Academic network design

My network drawing separates production lines into 10.10.10.0/24 and 10.10.11.0/24, with PLCs, HMIs, remote I/O, switches, and a connection toward the office network. Each line includes PROFIBUS-addressed encoders, a drive, and robots.

This demonstrates topology and address documentation, not deployment or commissioning. The original drawing still needs clearer PROFIBUS bus/master notation and correction of a duplicated remote-I/O label.

06 / Embedded programming

PIC32 sensor and peripheral code.

C · PIC32 · I²C · Timers · PWM · UART · Development exercise

My submitted C file includes routines for magnetic angle sensing, timer interrupts, PWM configuration, ultrasonic timing, and UART transmission. The excerpt below combines the sensor bytes and scales a 12-bit angle reading to degrees.

I2C_getByte(RAW_ANGLE_L, &ByteLow);
I2C_getByte(RAW_ANGLE_H, &ByteHigh);
angle = (ByteHigh << 8) | ByteLow;
*value = (double)angle * 360 / 4096;

This is evidence of peripheral-programming work, not a successful PID balancing demonstration. The full submitted control loop resets measurement/history, has zero integral and derivative gains, and needs timing, output-limiting, and shared-data handling corrections before closed-loop performance can be established.
